# Spec Delta

## ADDED Requirements

### Requirement: Пределы размеров кадра

Система SHALL применять к загружаемой картинке пределы не только по размеру
файла, но и по размерам кадра: сторона MUST быть не больше 8000 px, а число
пикселей — не больше 40 000 000. Превышение этих пределов MUST давать ответ
`413` и MUST NOT создавать объект в хранилище.

#### Scenario: Превышены размеры кадра

- **WHEN** авторизованный пользователь загружает картинку со стороной больше 8000 px или более 40 000 000 пикселей
- **THEN** ответ `413`
- **AND** объект в хранилище не создан

#### Scenario: Допустимые размеры кадра приняты

- **WHEN** сторона картинки не больше 8000 px, а число пикселей не больше 40 000 000
- **THEN** проверка размеров кадра проходит
- **AND** картинка сохраняется после успешной проверки типа и декодирования

### Requirement: Нормализация загруженной картинки

Принятую картинку система MUST перекодировать без метаданных исходного файла
(включая EXIF) и MUST уменьшить её длинную сторону до 1024 px, сохраняя
пропорции; меньшие изображения MUST NOT увеличиваться. По публичному URL MUST
отдаваться нормализованное изображение.

#### Scenario: Большая картинка уменьшена

- **WHEN** загружена корректная картинка с длинной стороной больше 1024 px
- **THEN** в хранилище сохраняется изображение с длинной стороной 1024 px и прежними пропорциями
- **AND** по выданному URL отдаётся корректное изображение

#### Scenario: Метаданные удалены

- **WHEN** загружен JPEG или PNG с метаданными (например, EXIF)
- **THEN** сохранённые байты не содержат метаданных исходного файла
- **AND** изображение по выданному URL остаётся корректным
