# Spec Delta

## ADDED Requirements

### Requirement: Smoke-проверка self-host

Репозиторий SHALL предоставлять воспроизводимую smoke-проверку self-host,
запускаемую целью `make smoke` и в CI. Проверка MUST собирать образ,
поднимать compose из чистого состояния, дожидаться healthcheck `pg_isready`
у PostgreSQL и ответов `200` от `GET /healthz` и `GET /readyz`. При любом
исходе проверка MUST удалять созданные ею контейнеры и volume, чтобы не
оставлять состояние и данные между прогонами. Обычный запуск
`docker compose up` MUST NOT зависеть от выполнения smoke-проверки.

#### Scenario: Успешный прогон с чистого состояния

- **WHEN** пользователь или CI выполняет `make smoke` на чистом checkout
- **THEN** проверка собирает образ и поднимает `app` и `postgres`
- **AND** дожидается состояния healthy у PostgreSQL по `pg_isready`
- **AND** получает `200` от `GET /healthz` и `GET /readyz`
- **AND** завершает прогон успешно

#### Scenario: Приложение не стало готово

- **WHEN** `GET /healthz` или `GET /readyz` не начинает отвечать `200` за
  отведённое время
- **THEN** smoke-проверка завершается с ненулевым кодом
- **AND** выводит логи `app` и `postgres` для диагностики

#### Scenario: Очистка после любого исхода

- **WHEN** smoke-проверка завершается успешно или с ошибкой
- **THEN** контейнеры и volume, созданные для проверки, удаляются
- **AND** повторный прогон начинает с чистого состояния

#### Scenario: Обычный запуск не зависит от smoke-проверки

- **WHEN** пользователь выполняет `docker compose up --build -d`
- **THEN** приложение запускается без обязательного предварительного
  выполнения `make smoke`
- **AND** проверка остаётся отдельной целью и шагом CI
