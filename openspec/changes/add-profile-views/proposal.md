# Proposal

## Why

Автор опроса не может управлять своей работой: в API нет списка «мои опросы»,
нельзя закрыть или удалить свой опрос, а сменить пароль можно только через
поддержку. Из-за этого автор вынужден просить об этом вручную, а данные о его
опросах размазаны по общему каталогу.

## What Changes

- `GET /api/v1/me/tierlists` — список опросов автора: только свои, со статусом
  и агрегатами (число ответов, дата создания, состояние).
- `PATCH /api/v1/tierlists/{id}` — закрытие и переоткрытие своего опроса.
- `DELETE /api/v1/tierlists/{id}` — удаление своего опроса.
- Чужой опрос для этих операций — `404` (не раскрываем существование).
- `POST /api/v1/me/password` — смена пароля; все сессии пользователя, кроме
  текущей, инвалидируются.
- Страница профиля `/profile` со списком опросов и агрегатами.

Не ломаем существующие маршруты каталога и публичных страниц.

## Capabilities

### New Capabilities

- `author-profile`: управление автором своим профилем и своими опросами —
  список, закрытие/удаление, смена пароля.

### Modified Capabilities

Нет: поведение публичного каталога и прохождения опроса не меняется.

## Impact

- API: новые маршруты `/api/v1/me/*` и `PATCH/DELETE /api/v1/tierlists/{id}`.
- Фронтенд: новая страница профиля и клиентские вызовы.
- Сессии: смена пароля закрывает остальные сессии пользователя.
- Хранилище: выборки опросов по владельцу и агрегаты.
