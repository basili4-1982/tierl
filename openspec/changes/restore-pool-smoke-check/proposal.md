# Proposal

## Why

TIERL-47 (PR 108) «Pool smoke 6: repo из проекта» заявляет проверку TT-148:
воркер стартует без переменной `REPO` в окружении и получает репозиторий из
аренды (lease). Аудит `docs/audits/TIERL-47.md` зафиксировал `gap`: в коде нет
ни воркера пула, ни lease-клиента, ни smoke-теста TT-148, а `pool-smoke.txt`
содержит только маркер `smoke`. У работы нет живой цепочки «цель → спека →
код», поэтому требование нужно восстановить и запланировать реализацию.

## What Changes

- Вводится capability `worker-pool` с требованием TT-148: воркер запускается
  без `REPO` в окружении, репозиторий получает из аренды, а smoke-проверка
  подтверждает оба условия.
- В `tasks.md` выносятся задачи на реализацию отсутствующей проверки: поднять
  воркер пула без `REPO`, получить репозиторий из lease и добавить smoke-тест,
  который падает, если `REPO` задан или репозиторий не пришёл из аренды.
- Избыточный файл-маркер `pool-smoke.txt` не входит в этот change: его
  удаление — отдельный change `remove-pool-smoke-artifact`.
- Поведение кода, тестов, контракта и применённых миграций в этом change не
  меняется.

## Capabilities

### New Capabilities

- `worker-pool`: внешний пул воркеров, который получает репозиторий проекта из
  аренды (lease), а не из переменной окружения `REPO`, и проверяется pool
  smoke.

Новое имя `worker-pool` вводится потому, что ни один существующий якорь
(`accounts`, `tierlists`, `submissions`, `results`, `catalog`, `reports`,
`sharing`, `author-profile`, `item-images`, `self-host`) не описывает пул
воркеров и аренду репозитория. `self-host` относится к запуску и деплою самого
tierl, а не к внешнему harness воркеров, поэтому его использование было бы
ложной привязкой.

### Modified Capabilities

Нет. Существующие capability не меняют своих требований.

## Impact

- Спека: новый `openspec/specs/worker-pool/spec.md` после архивации.
- Код (задачи на реализацию, не в этом change): воркер пула и lease-клиент
  внешнего harness, smoke-проверка TT-148.
- Контракт API, фронтенд и applied-миграции не затрагиваются.
- Аудит: `docs/audits/TIERL-47.md` фиксирует вердикт `gap` и ссылается на этот
  change; избыточный `pool-smoke.txt` удаляется change'ем
  `remove-pool-smoke-artifact`.
