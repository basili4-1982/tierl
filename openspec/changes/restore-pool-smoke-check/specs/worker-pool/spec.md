# Spec Delta

## Purpose

Восстановить требование к пулу воркеров: воркер получает репозиторий проекта
из аренды (lease), а не из переменной окружения `REPO`, и это подтверждается
pool smoke-проверкой.

## ADDED Requirements

### Requirement: Репозиторий воркера приходит из аренды

Воркер пула SHALL запускаться без переменной `REPO` в окружении. Репозиторий
проекта воркер MUST получать из аренды (lease). Наличие `REPO` MUST NOT быть
обязательным условием запуска воркера.

#### Scenario: Воркер стартует без REPO

- **WHEN** harness запускает воркер в окружении, где `REPO` не задан
- **THEN** воркер стартует
- **AND** получает репозиторий проекта из аренды

#### Scenario: Аренда выдаёт репозиторий

- **WHEN** воркер запрашивает аренду проекта
- **THEN** ответ аренды содержит расположение репозитория
- **AND** воркер использует именно это расположение

### Requirement: Smoke-проверка TT-148

Pool smoke SHALL проверять, что у воркера нет `REPO` в окружении и что
репозиторий пришёл из аренды. Проверка MUST падать, если `REPO` задан или если
репозиторий не получен из аренды.

#### Scenario: Проверка проходит для корректного воркера

- **WHEN** pool smoke запускает воркер без `REPO`, и воркер получает репозиторий из аренды
- **THEN** проверка завершается успешно

#### Scenario: Проверка ловит REPO в окружении

- **WHEN** pool smoke запускает воркер с заданным `REPO`
- **THEN** проверка завершается ошибкой

#### Scenario: Проверка ловит отсутствие аренды

- **WHEN** воркер запускается без `REPO`, но репозиторий не получен из аренды
- **THEN** проверка завершается ошибкой
