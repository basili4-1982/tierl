# Spec Delta

## Purpose

Дать автору опроса картинки элементов: загрузка файла, хранение вне базы,
публичный URL и удаление файла вместе с элементом.

## ADDED Requirements

### Requirement: Загрузка картинки элемента

Система SHALL принимать картинку авторизованного пользователя и MUST отклонять
файлы, которые не являются поддерживаемым изображением или превышают лимит.
Загруженные байты MUST храниться в объектном хранилище, а не в базе данных.

#### Scenario: Корректная картинка загружена

- **WHEN** авторизованный пользователь отправляет `POST /api/v1/media` с PNG до 5 МиБ
- **THEN** ответ `200` и JSON с полем `url`
- **AND** по этому URL отдаётся изображение

#### Scenario: Слишком большой файл отклонён

- **WHEN** размер файла больше лимита
- **THEN** ответ `413`
- **AND** объект в хранилище не создан

#### Scenario: Не-картинка отклонена

- **WHEN** отправлен файл, содержимое которого не PNG, JPEG, WebP или GIF
- **THEN** ответ `415`
- **AND** объект в хранилище не создан

#### Scenario: Битый файл отклонён

- **WHEN** содержимое похоже на картинку по заголовку, но не декодируется
- **THEN** ответ `400`

#### Scenario: Гость не загружает

- **WHEN** запрос без сессии
- **THEN** ответ `401`

### Requirement: Картинка привязана к элементу

Система SHALL сохранять URL картинки в элементе опроса и MUST принимать только
URL, выданный загрузкой этому же пользователю.

#### Scenario: Автор ставит картинку элементу

- **WHEN** автор отправляет `PATCH /api/v1/tierlists/{slug}` с `image_url`, полученным от загрузки
- **THEN** элемент сохраняет URL
- **AND** `GET /api/v1/tierlists/{slug}` возвращает этот URL у элемента

#### Scenario: Чужой URL отклонён

- **WHEN** передан URL, полученный загрузкой другого пользователя или внешний адрес
- **THEN** ответ `400`
- **AND** элемент не меняется

### Requirement: Удаление файла вместе с элементом

Система SHALL удалять файл картинки, когда элемент исчезает из опроса или его
картинка заменяется, и когда удаляется сам опрос. Сбой удаления файла MUST NOT
отменять изменение опроса.

#### Scenario: Элемент удалён из опроса

- **WHEN** `PATCH /api/v1/tierlists/{slug}` приходит без ранее сохранённого элемента
- **THEN** файл этого элемента удалён из хранилища
- **AND** URL элемента больше не отдаёт изображение

#### Scenario: Картинка заменена

- **WHEN** элемент получает новый `image_url`
- **THEN** прежний файл удалён, новый доступен по своему URL

#### Scenario: Опрос удалён

- **WHEN** автор удаляет опрос
- **THEN** файлы всех его элементов удалены

### Requirement: Редактор работает с картинками

Интерфейс редактора SHALL позволять выбрать файл для элемента, показать
загруженную картинку и убрать её.

#### Scenario: Выбор файла в редакторе

- **WHEN** автор выбирает файл у элемента
- **THEN** файл загружается через API и картинка появляется у элемента
- **AND** сохранение опроса отправляет `image_url` элемента

#### Scenario: Ошибка загрузки видна автору

- **WHEN** загрузка отклонена (`413`/`415`/`400`)
- **THEN** редактор показывает сообщение об ошибке и не привязывает картинку
