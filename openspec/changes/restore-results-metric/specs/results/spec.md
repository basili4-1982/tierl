# Spec Delta

## ADDED Requirements

### Requirement: Метрика сходства и порог

Система SHALL вычислять сходство ответов по формуле
`1 - sum|ta-tb| / (N*(T-1))` по элементам, размещённым в обоих ответах, где
`T` — число тиров, `N` — размер пересечения. Пары с `N < 3` MUST NOT
учитываться; значение MUST лежать в `[0, 1]`. Статистика MUST возвращать
порог «думают как ты» `similarity_threshold`; по умолчанию он MUST быть равен
`0.80`.

#### Scenario: Идентичные ответы дают максимальное сходство

- **WHEN** два ответа размещают не менее 3 общих элементов в одинаковых тирах
- **THEN** сходство равно `1`
- **AND** пара учитывается в доле «думают как ты»

#### Scenario: Малое пересечение не учитывается

- **WHEN** два ответа имеют меньше 3 общих размещённых элементов
- **THEN** сходство не определено
- **AND** пара не входит в долю «думают как ты»

#### Scenario: Порог сходства возвращается в статистике

- **WHEN** клиент запрашивает `GET /api/v1/results/{id}/stats`
- **THEN** ответ содержит `similarity_threshold`
- **AND** значение по умолчанию равно `0.8`
- **AND** доля считается по парам со сходством не ниже этого порога
