# Proposal

## Why

Аудит TIERL-47 показал, что PR 108 «Pool smoke 6: repo из проекта» не оставил
в репозитории реализации заявленной проверки TT-148 (воркер без `REPO` в env,
репозиторий из аренды). Единственный артефакт — файл `pool-smoke.txt` со
строкой `smoke`. Он не следует ни из одного требования tierl и не проверяет
TT-148, то есть является избыточным файлом в продуктовом репозитории.

## What Changes

- Удаляется `pool-smoke.txt` из корня репозитория как избыточный артефакт
  внешнего worker-pool harness.
- Проверяется, что на файл нет ссылок в CI, Makefile, документации и коде.
- Продуктовые спеки и код не меняются: это уборка tooling-артефакта.

## Capabilities

### New Capabilities

Нет. Пул воркеров и аренда репозитория — не способность продукта tierl.

### Modified Capabilities

Нет. Ни один якорь (`accounts`, `tierlists`, `submissions`, `results`,
`catalog`, `reports`, `sharing`, `author-profile`, `item-images`, `self-host`)
не описывает worker-pool harness и переменную `REPO`. `self-host` относится к
запуску и деплою самого tierl, поэтому привязка к нему была бы ложной.

## Impact

- Удаляется только `pool-smoke.txt`; код, тесты, контракт, миграции и живые
  спеки OpenSpec не затрагиваются.
- Проверка TT-148 остаётся у владельца внешнего пула воркеров: в этом
  репозитории для неё нет ни кода, ни требования.
- Аудит: `docs/audits/TIERL-47.md` фиксирует вердикт `excess` и эскалацию
  TT-148 человеку.
