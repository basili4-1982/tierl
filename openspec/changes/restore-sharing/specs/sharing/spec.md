# Spec Delta

## Purpose

Восстановить требование к шерингу опроса и результата: серверные страницы
`/t/<slug>` и `/r/<id>` отдают OG/Twitter-метатеги, результату рендерится PNG
1200x630, ответы кэшируются, unlisted закрыт от индексации, а SPA fallback
продолжает работать.

## ADDED Requirements

### Requirement: OG- и Twitter-метатеги на страницах шеринга

Система SHALL отдавать на `GET /t/<slug>` и `GET /r/<id>` серверный HTML с
метатегами `og:title`, `og:image` и `twitter:card`, а также с описанием,
canonical-ссылкой и `og:url`. Пользовательские значения MUST экранироваться в
HTML. Для результата заголовок и картинка MUST относиться к этому результату.

#### Scenario: Страница опроса содержит OG-метатеги

- **WHEN** краулер запрашивает `GET /t/<slug>` для читаемого опроса
- **THEN** ответ содержит `og:title` с названием опроса
- **AND** ответ содержит `og:image` и `twitter:card`
- **AND** canonical и `og:url` указывают на `/t/<slug>`

#### Scenario: Страница результата содержит OG-метатеги

- **WHEN** клиент запрашивает `GET /r/<id>` для существующего результата
- **THEN** ответ содержит `og:title` с названием опроса и признаком результата
- **AND** ответ содержит `og:image` и `twitter:card`
- **AND** canonical и `og:url` указывают на `/r/<id>`

#### Scenario: Пользовательский текст экранируется

- **WHEN** название или описание содержит HTML-спецсимволы
- **THEN** метатеги содержат экранированное значение
- **AND** разметка страницы не ломается

### Requirement: Серверный PNG-превью 1200x630

Система SHALL рендерить на сервере PNG-изображение размером 1200x630 для
результата по `GET /r/<id>/og.png` (и для опроса по `GET /t/<slug>/og.png`) и
отдавать его с `Content-Type: image/png`. PNG результата SHALL показывать
название опроса и доску тиров участника, если данные результата доступны.

#### Scenario: Результат получает PNG 1200x630

- **WHEN** клиент запрашивает `GET /r/<id>/og.png` для существующего результата
- **THEN** ответ `200` с `Content-Type: image/png`
- **AND** изображение имеет размер 1200x630 пикселей

#### Scenario: Неизвестный результат не рендерится

- **WHEN** запрошен OG-ресурс для несуществующего или нечитаемого результата
- **THEN** ответ `404`

### Requirement: Кэширование страниц и превью

Система SHALL возвращать кэш-заголовки для страниц шеринга и PNG-превью.
Публичные страницы и картинки MUST кэшироваться разделяемыми кэшами с
разумным TTL; PNG MUST получать `ETag` для повторной валидации.

#### Scenario: Публичный PNG кэшируется

- **WHEN** запрошен OG-ресурс публичного опроса или результата
- **THEN** ответ содержит `Cache-Control` с `public` и `max-age`
- **AND** ответ содержит `ETag`

#### Scenario: Публичная страница кэшируется

- **WHEN** запрошена страница шеринга публичного опроса или результата
- **THEN** ответ содержит `Cache-Control` с `public`, `max-age` и `s-maxage`

### Requirement: noindex для unlisted

Страницы и OG-ресурсы unlisted-опроса MUST отдаваться с запретом индексации:
HTML содержит `<meta name="robots" content="noindex,nofollow">`, а ответ —
заголовок `X-Robots-Tag`. Кэш unlisted MUST быть приватным и неразделяемым.
Unlisted-опрос MUST NOT попадать в каталог.

#### Scenario: Unlisted-страница закрыта от индексации

- **WHEN** запрошена `GET /t/<slug>` или `GET /r/<id>` unlisted-опроса
- **THEN** HTML содержит `noindex`
- **AND** ответ содержит `X-Robots-Tag` с `noindex`
- **AND** `Cache-Control` не допускает публичное кэширование

#### Scenario: Unlisted-превью не кэшируется публично

- **WHEN** запрошен OG-ресурс unlisted-опроса
- **THEN** ответ содержит `X-Robots-Tag` с `noindex`
- **AND** `Cache-Control` содержит `private` и `no-store`

#### Scenario: Unlisted не попадает в каталог

- **WHEN** unlisted-опрос создан и существует публичный опрос
- **THEN** каталог содержит только публичный опрос

### Requirement: Сохранение SPA fallback

Серверные маршруты шеринга MUST занимать только `/t/`, `/r/` и `/og/`; прочие
неизвестные пути без файлового расширения MUST по-прежнему отдавать
`index.html` SPA. Зарезервированные серверные префиксы MUST NOT отдавать SPA.

#### Scenario: Клиентский маршрут получает SPA

- **WHEN** запрошен неизвестный путь без расширения, например `/profile`
- **THEN** ответ `200` с `index.html`

#### Scenario: Серверный префикс не отдаёт SPA

- **WHEN** запрошен неизвестный путь под `/api`, `/healthz` или `/og`
- **THEN** ответ `404`
