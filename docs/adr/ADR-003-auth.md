# ADR-003: email и пароль, argon2id, серверные сессии

Статус: принято

## Контекст

Нужна простая аутентификация без зависимости от внешних провайдеров, пригодная для self-host. Мы контролируем и бэкенд, и SPA на одном origin.

## Решение

- Регистрация и вход по email и паролю. Email приводится к нижнему регистру, уникален.
- Пароль 10–128 символов. Хэш — argon2id, параметры (память, итерации, параллелизм) из конфига; хэш хранит свои параметры, что позволяет их повышать. Сравнение — constant-time.
- Сессии серверные, в Postgres. В cookie — случайный токен 32 байта, в БД — только его SHA-256. Cookie: `HttpOnly; Secure; SameSite=Lax`.
- CSRF-токен на всех изменяющих запросах (POST/PATCH/DELETE).
- Выход завершает текущую сессию; есть «выйти со всех устройств».
- Подтверждение email: токен 32 байта, в БД SHA-256, TTL 24 часа, одноразовый; повторная выдача инвалидирует предыдущий. Без подтверждения опросы создавать нельзя.
- Сброс пароля по ссылке из письма: токен 32 байта, в БД SHA-256, TTL 1 час, одноразовый. Ответ на запрос сброса всегда одинаковый, существование адреса не раскрывается. После смены пароля все сессии отзываются, остальные reset-токены помечаются использованными.
- Rate limiting на вход, регистрацию и сброс по IP-хэшу и по email (issue #10).
- Письма отправляются через интерфейс `Mailer` (SMTP; `LogMailer` в тестах).

## Альтернативы

- JWT: отзыв и «выйти везде» требуют серверного состояния, то есть те же сессии, но сложнее.
- OAuth/соцсети: внешняя зависимость и сложнее self-host; отложено (см. SPEC, раздел «Вне MVP»).
- bcrypt/scrypt: argon2id устойчивее к GPU-перебору и является текущей рекомендацией OWASP.
- Magic link вместо пароля: хуже для повторных входов и зависит от доставки почты на каждый вход.

## Последствия

- Каждый запрос с сессией читает Postgres; для MVP приемлемо, при росте добавляется кэш.
- Утечка БД не раскрывает рабочие токены сессий и писем (хранятся хэши).
- Нужна почтовая инфраструктура (Mailpit локально, SMTP в проде); без неё регистрация не завершается.
- Параметры argon2id нужно подбирать под железо деплоя; значения по умолчанию в `.env.example`.
